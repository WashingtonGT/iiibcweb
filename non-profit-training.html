The fluency spine

Four habits run through every module

No one uses AI on real work until they have completed the fluency foundation and learned the do-not-use rules. Staff learn the 4D habits before they touch any tool (Anthropic and GivingTuesday, AI Fluency for Nonprofits).

Delegation

Decide what to hand to AI and what to keep human, especially high-stakes beneficiary decisions.

Description

Prompt clearly: give context and constraints so output is useful and safe, with less rework.

Discernment

Evaluate output critically for bias, error, and confident-but-wrong answers before you trust it.

Diligence

Verify, disclose, and own the results. The people you serve can't absorb AI mistakes.

How to run the kit

Built for lean teams and tight budgets

1 · Assess

Run the readiness assessment for a section-by-section profile. Prioritize the modules whose sections scored Foundational or Developing.

2 · Deliver

Use the free and low-cost format menu: self-paced courses, lunch-and-learns, a shared prompt library, and training built into onboarding so knowledge survives turnover.

3 · Measure

Each module ends with an outcome scorecard. Track with the Kirkpatrick model: reaction → learning and confidence → applied behavior → mission impact.
